For a TeX/PDFLaTeX paper submission, arXiv supports accompanying code as
ancillary material in an anc directory at the submission root. Keep all five
project folders together so the Core4loop -> Core3loop relative dependency
continues to work after download. Refer to the supplementary code from the
paper and check the upload preview. The ancillary-file mechanism is not
currently supported for PDF-only submissions.
